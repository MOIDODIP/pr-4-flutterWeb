# Практическая работа 4

Проект подключает библиотечную систему к REST API через Dio. Данные больше не берутся из репозитория в памяти: книги и авторы загружаются через API.

## Запуск

1. Запустите учебный сервер:

```powershell
node mock-server.js --port 8080 --origin http://localhost:5555
```

2. Проверьте сервер в браузере:

`http://localhost:8080/api/__health`

3. Установите зависимости и запустите Flutter Web на фиксированном порту:

```powershell
flutter pub get
flutter run -d chrome --web-port=5555
```

Другой адрес API задаётся параметром сборки:

```powershell
flutter run -d chrome --web-port=5555 --dart-define=API_BASE_URL=http://192.168.1.10:8080/api
```

Без запущенного сервера приложение показывает состояние ошибки с понятным сообщением и кнопкой повторной загрузки.
